# Project Hercules

Project Hercules is an in-development game engineering portfolio project created in preparation for 2027 industrial placement applications.

## Current status
Planning and environment setup.

## Project goal
Create a small but polished Unreal Engine gameplay experience supported by a telemetry backend that records selected gameplay events.

## Planned technologies
- Unreal Engine 5
- C++
- Java
- Spring Boot
- MySQL
- Git and GitHub

## Planned first milestone
- Create and run a C++ Unreal Engine project
- Implement basic player movement and interaction
- Establish a clean Git repository
- Document development progress

## Important note
The scope and architecture may change as development progresses.
